# 24 鬼の足を遅くした鬼ごっこ（tagrs）で、信念の差は出るか

- **問い**: tagr では学習した方策が 2〜4（生存 24〜42 step）で頭打ちで、何もしない方策（ランダム 3.0、停止 3.2）と同じ水準にいる。鬼を遅くして「うまく逃げれば長く生きられる」課題にすると、学習は進むか。light v2 と基準線の差は出るか（ユーザー 2026-11-14「足を遅くした簡易化鬼ごっこも試してほしい」）。
- **課題 tagrs**: tagr（距離観測、鬼 3 体、horizon 200、1 step 0.1）と同じで、鬼の追跡の速さだけをプレイヤー最大速度の 0.8〜1.0 倍から **0.5〜0.7 倍**にした（`ghost_speed_min: 0.5`、`ghost_speed_max: 0.7`）。
- **速さを選んだ根拠**（[TAG_LIMIT.md](../results/reports/tag_limit_2026-11-14/TAG_LIMIT.md)、生存 step、リターンはその 0.1 倍）:

  | 鬼の速さ | ランダム | 停止 | 旋回し続ける | 全状態の反発 | 全状態の先読み |
  |---|---:|---:|---:|---:|---:|
  | 0.8〜1.0（tagr） | 30.0 | 31.7 | 35.9 | 81.5 | 136.8 |
  | 0.6〜0.8 | 40.5 | 39.7 | 66.7 | 103.8 | 166.9 |
  | 0.5〜0.7（tagrs） | 41.0 | 45.0 | 81.2 | 137.0 | 183.7 |
  | 0.4〜0.6 | 51.6 | 54.0 | 103.3 | — | — |

  0.5〜0.7 は、何もしない方策が 4.1〜4.5、鬼の位置が分かる方策が 13.7〜18.4 で、差が最も読みやすい。
- **腕（campaign）**: light v2 の素 `trysvgdlight2-tagrs-tf-svgd-v1`、GRU `trysvgd-tagrs-gru-v1`、粒子フィルタ `trysvgd-tagrs-pf-v3-v1`。幅は tagr と同じ（観測の次元が同じなので FLOPs の対応も同じ）。1293 update、seed 10–14、15 本。

- **状態**: 2026-11-14、設定 3 個・ジョブ 15 本・テストを準備、CPU の短い試走済み。同日 06:14 に math へ 15 本を投入（木 v31、ユーザー「投入OK」）: seed 10–12 の 9 本は待ちの先頭（GRU → PF v3 → light v2）、seed 13–14 の 6 本は最後尾。2026-11-15 朝に seed 10–12 の 9 本が完走。

## 結果の解説

2026-11-15 時点、seed 10–12。全 run 共通の 100 話の検証平均（決定的方策。リターン = 生存 step × 0.1、± は seed 間の標準誤差、括弧は seed ごと）。

| 腕 | tagrs（鬼 0.5〜0.7） | 参考: tagr（鬼 0.8〜1.0） |
|---|---:|---:|
| PF v3 | **10.27 ± 0.30**（10.18 / 10.82 / 9.80） | 4.10（4.82 / 4.13 / 3.36） |
| GRU | 8.08 ± 1.71（9.47 / 4.67 / 10.10） | 4.27（3.80 / 3.40 / 5.60） |
| light v2 | 6.72 ± 0.83（7.54 / 7.56 / 5.07） | v1 の素 3.42（v2 は走行中） |
| 何もしない（ランダム / 停止） | 4.1 / 4.5 | 3.0 / 3.2 |
| 旋回し続ける | 8.1 | 3.6 |
| 全状態の反発 / 先読み | 13.7 / 18.4 | 8.2 / 13.7 |

- tagr では学習した方策が「旋回し続けるだけ」（3.6）と同じ水準に固まっていたが、tagrs では腕の間に差が出た。PF v3 は 3 seed とも旋回（8.1）を上回り、GRU は 2 seed が上回って 1 seed（4.67）は何もしない水準のまま、light v2 は 3 seed とも旋回より下。
- どの腕も全状態の反発（13.7）には届いていない。何もしない 4.5 を 0、反発 13.7 を 1 とすると PF v3 0.63、GRU 0.39、light v2 0.24。
- light は v2 の素だけを走らせた。v2 は mirror2 / tps / Car-Flag で v1 より悪い（[23](23-light-default-v2.md)）ので、light v2 が最下位である理由が「light だから」か「v2 だから」かは、この 9 本では分けられない。

## 結論メモ

- 鬼を 0.5〜0.7 倍に遅くすると学習が進み、腕の差が出る: PF v3 10.27 > GRU 8.08 > light v2 6.72（検証 100 話、seed 10–12）。目安は何もしない 4.1〜4.5、旋回 8.1、全状態の反発 13.7。
- 旋回を安定して上回ったのは PF v3 だけ。GRU は seed 11 が 4.67 で学習できず、light v2 は 3 seed とも旋回より下。
- light v1 の素を tagrs で走らせていないので、light v2 の低さが v2 のせいかどうかは未確定。
