比較元は `476ea92`。コミットなし。`config/`・`jobs/`・`results/` は変更していない。
`CLAUDE.md` は作業ツリーと親ディレクトリに見つからず、brief・既存レビュー・docs を確認した。
分担には指定どおり `model="gpt-6.1-terra"` の sub-agent を3つ起動し、差分を親側で確認した。

1. **prefix replay**：時刻ごとに有効環境を集め、initial / recursive の分岐別にバッチ処理する。
   パディング部分は sampler に渡さず、粒子を更新せず、乱数も要求しない。
   分岐判定のホスト転送は prefix 全体で一度。`full` の履歴グラフ、`tbptt_1` の切断、
   空 prefix の初期状態、rollout 中の reset を維持した。
2. **recondition**：保存履歴を同様に有効行・分岐別で処理する。空履歴のゼロ化と
   `RuntimeError`、`track_grad=False` を維持。GRU/RNN の再調整もバッチ化した。
   粒子フィルタと有効な dropout を含む recurrent モデルは乱数順序を守るため逐次処理を残す。
3. **最終 score の省略**：`EnergyBelief.particles_from_noise(need_scores=True)` を追加。
   `False` は最終 readout のみ省き、score として `None` を返す。
   ULA/SVGD/SMI の transport、SMI の成分スケール更新、energy/direct/direct_joint の内部 score は変更しない。
   prefix、recondition、score を読まない alpha_pool の評価・bootstrap に適用した。
   policy と value の両 encoder を確認する。rollout は診断指標でも score を使うため維持し、
   main replay も従来どおり score を返す。
4. **saved diffusion chain のバッチ化は不採用**：denoiser だけを `[steps × batch]` にまとめても、
   float32・`min_std=0.05` の実際の sampled chain で log-probability の最大絶対差が
   **1.07288361e-5**、最大相対差が **1.79224498e-5** となった。
   `atol=rtol=1e-6` を満たさないため `log_prob_chain` と PPO objective は元の逐次評価を維持した。
   [再現スクリプト](check_diffusion_batching.py) を残した。小分散だけの fallback では通常設定を守れない。
5. **rollout entropy**：score / baseline 共通で固定分散から `chain_entropy` を計算し、
   二度目の denoiser を除去した。元と同じ dtype、`min_std` clamp、`Normal.entropy`、
   action 軸・step 軸の還元を使う。対象は従来の「squash 前の Gaussian chain entropy」であり、
   squash 後の行動 entropy に定義を変更していない。
6. **検証**：下記の参照実装との比較、全体テスト、CPU 計測を実施した。

## CPU 計測

Windows、PyTorch **2.3.1+cpu**、`torch.set_num_threads(1)`。
`trysvgd_tagr_tf-ula.json` を読み、4 env × 16 steps、minibatch/microbatch 64、
PPO 128 steps、prediction pretrain 64 steps、eval 1 episode、seed 10 に上書きした。
合計192環境 steps（pretrain 1更新＋PPO 2更新）。テスト終了後、before → after を連続して各1回測定した。
before は `git show HEAD` のモジュールをメモリ内に読み込み、共有ソースは書き戻していない。
短い単回測定であり、GPU・長期 campaign の倍率を保証するものではない。

| prediction pretrain update（ログ名 ppo_update、update 1） | 1.385 | 1.339 | 1.03 |
| PPO update 2 | 7.973 | 4.101 | 1.94 |
| PPO update 3 | 12.793 | 5.678 | 2.25 |
